# Install agents

Installs, updates, reinstalls or removes Taxiway's scheduled agents.

Arguments, both optional: an agent `id` (default: every agent), then
`reinstall` or `remove` (default: install or update).

Follow [`taxiway-agents` Install](../taxiway-agents/SKILL.md#install).
