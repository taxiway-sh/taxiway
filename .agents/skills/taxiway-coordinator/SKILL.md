# Coordinator

Starts this session as the maintainer's coordinator, from the repository
alone. Argument, optional: a message to the coordinator, whose language it
uses.

Follow [`taxiway-workflow` Coordinator](../taxiway-workflow/SKILL.md#coordinator).
